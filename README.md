# Instagram 게시용 미디어

인스타 게시물 파일만 두는 저장소예요. 계정마다 폴더를 나눠요.

| 계정 | 위치 | 비고 |
|---|---|---|
| @aneun.cheok (아는 척) | 맨 위 폴더들 (`robot/`, `pixar/`, `vaccine/` …) | 예약 게시가 이 주소를 쓰고 있어서 위치를 그대로 둬요 |
| @leftright.translator (좌우통역) | `leftright/` 안 | `leftright/01-future-fund/`처럼 `번호-주제` |

- 새 아는 척 편: 맨 위에 `주제/` 폴더
- 새 좌우통역 편: `leftright/NN-주제/` 폴더, 파일 이름은 `leftright_NN_...`
- 게시용 영상·커버만 올려요. 제작 파일·원본은 올리지 않아요.
